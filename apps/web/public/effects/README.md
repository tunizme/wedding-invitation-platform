# Effect artwork catalog

These files are the public reference artwork observed in the Cinelove Effects panel on 2026-10-15 and copied locally for the requested clone. Runtime uses local paths only. `manifest.json` records source URLs, byte counts and SHA-256 hashes; missing JPEG posters were generated from the corresponding downloaded WebM files.

The files retain their original visual content. No account credentials, session data or private account images are included. Custom user images remain managed assets and are never written into this catalog.
